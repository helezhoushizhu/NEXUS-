## 三、主要实验内容

### 1. 图像滤波

分别使用均值滤波、方框滤波、高斯滤波和中值滤波处理原始图像，并比较不同方法的平滑效果。

在此基础上，尝试将均值滤波和高斯滤波结合，观察连续滤波后的图像变化。

### 2. 图像二值化

首先将彩色图像转换为灰度图，再使用 `cv2.threshold()` 进行二值化，将像素划分为黑色和白色两类。

### 3. 腐蚀与膨胀

利用 `cv2.erode()` 和 `cv2.dilate()` 处理二值图像，观察不同迭代次数对图像中白色区域大小和细节的影响。

### 4. 边缘检测

使用 Sobel 算子计算图像在 x、y 方向的亮度梯度，并利用 Canny 算法提取图像轮廓。

实验中发现，直接进行 Canny 检测可能产生较多杂乱边缘，因此尝试先进行高斯滤波，再提取边缘。

### 5. 铅笔轮廓画

通过灰度化、高斯滤波和 Canny 边缘检测提取主要轮廓，最后对边缘图取反，得到白色背景、黑色线条的简化铅笔画效果。

```python
x, y, w, h = cv2.selectROI("Select Person", img, False, False)
```

## 四、思考题

### 思考题 1：比较不同滤波方法的原理、优缺点及适用场景

**（1）均值滤波**

均值滤波利用一个固定大小的窗口，对窗口中的所有像素求算术平均值，并用平均值替换中心像素。

优点是原理简单、计算效率高，可以减弱部分随机噪声。缺点是所有像素的权重相同，图像边缘两侧的像素也会参与平均，因此容易造成边缘模糊。此外，均值容易受到极端噪声值的影响。

**（2）高斯滤波**

高斯滤波同样进行加权平均，但使用高斯函数确定权重。距离中心较近的像素通常具有更大的权重，距离越远，权重越小。

相比简单的均值滤波，高斯滤波能够实现较为自然的平滑效果，通常适合处理高斯噪声。但由于它本质上仍然是加权平均，依然会损失一部分边缘和细节，对椒盐噪声的处理效果也不一定理想。

**（3）中值滤波**

中值滤波不计算平均值，而是将窗口内的像素排序，选择中位数替换中心像素。

它最大的优势是对极端异常值不敏感，因此非常适合处理椒盐噪声。相比均值滤波，中值滤波在很多情况下能够更好地保留边缘。不过，如果窗口过大，也可能导致细线、尖角等图像细节消失。

**（4）方框滤波**

方框滤波使用固定大小的窗口，对邻域内的像素进行求和计算。

当设置 `normalize=True` 时，方框滤波会对结果进行归一化，此时与相同窗口大小的均值滤波具有相同的效果。

优点是计算简单，能够进行快速的图像平滑。缺点是归一化后同样容易模糊边缘，对极端异常值较为敏感。如果不进行归一化，还需要注意输出数值可能过大。

**总结：**

这几种滤波方法的核心区别在于如何利用邻域信息。均值滤波取算术平均，高斯滤波取加权平均，中值滤波取排序后的中位数，归一化的方框滤波则与均值滤波等效。

实际应用中需要根据噪声类型和边缘保留要求选择滤波算法，而不是单纯追求最强的平滑效果。

### 思考题 2：如何处理激光雷达占据栅格地图中的孤立噪点？

激光雷达构建的占据栅格地图可能因为测量误差、环境干扰等原因，出现少量孤立的占据栅格或空闲栅格。

对于这类孤立噪点，可以考虑使用中值滤波，因为中值滤波能够有效减弱与周围栅格状态明显不同的异常值。

如果地图经过适当的二值化处理，也可以考虑使用形态学操作。例如，开运算（先腐蚀后膨胀）可用于去除较小的白色区域，闭运算（先膨胀后腐蚀）可用于填补较小的黑色空隙。

但需要注意，占据栅格地图中的白色、黑色不一定直接对应障碍物和空闲区域，实际处理前必须明确地图的数据编码。同时，地图中可能存在真实的小障碍物、狭窄通道和未知区域，如果直接进行强滤波，可能会删除重要信息。

在实际尝试中，我发现直接使用中值滤波可能导致地图中的部分细节减少，因此不能单纯地通过增大滤波窗口提高去噪强度。

更合理的做法是结合地图的实际情况，对确认属于噪声的孤立区域进行适度处理，同时尽可能保留真实障碍物和未知栅格信息。

### 思考题 3：如何利用图像处理方法实现摄像头自动对焦？

自动对焦的核心目标是找到能够使图像最清晰的镜头位置。

通常情况下，清晰图像包含更多高频细节，边缘处的亮度变化也更明显。因此，可以通过计算图像的清晰度评价指标来判断对焦效果。

一种常见方法是使用 Laplacian 算子：

1. 摄像头采集当前镜头位置下的图像。
2. 将图像转换为灰度图。
3. 使用 Laplacian 算子计算图像的二阶变化。
4. 计算 Laplacian 响应的方差，作为清晰度评价指标。
5. 调整镜头位置并重复计算。
6. 在合适的搜索范围内，找到使清晰度指标较大的镜头位置。

例如，可以使用 OpenCV 计算：

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
score = cv2.Laplacian(gray, cv2.CV_64F).var()
```

`score` 可以作为一种清晰度评价指标。对于同一场景，在其他条件相近时，较清晰的图像往往具有较大的 Laplacian 方差。

不过，清晰度指标也会受到噪声、场景纹理和光照等因素影响，因此不能简单认为分数越大就一定对焦越准确。

实际自动对焦系统还需要考虑镜头的机械调整、搜索策略以及对焦区域的选择。
